# Mathematical Object Origin Archive | Wave Front Set

## 1. Archive Information

- Standard Name: Wave front set
- Mathematical Field: Partial Differential Equations; Microlocal Analysis
- Abstract: The wave front set of a distribution records both the points where it is nonsmooth and the nonzero cotangent directions in which localized high-frequency decay fails. It was formed to address the microlocal regularity problem for linear partial differential equations: for an equation \(Pu=f\), determine which singularities of \(u\) are forced by \(f\), which can occur only in characteristic directions of \(P\), and how those singularities propagate.

## 2. Core Record

### Precise Description

Let \(\Omega\subset\mathbb{R}^n\) be open and \(u\in\mathcal D'(\Omega)\). A pair \((x_0,\xi_0)\in \Omega\times(\mathbb{R}^n\setminus\{0\})\) is **not** in the wave front set \(\operatorname{WF}(u)\) if there exist \(\phi\in C_c^\infty(\Omega)\), with \(\phi=1\) on a neighborhood of \(x_0\), and an open conic neighborhood \(\Gamma\) of \(\xi_0\) such that, for every \(N\geq 0\),
\[
  |\widehat{\phi u}(\xi)|\leq C_N(1+|\xi|)^{-N}
  \qquad (\xi\in\Gamma)
\]
for some constant \(C_N\). Thus \(\operatorname{WF}(u)\) is the set of localized directions in which the Fourier transform fails to decay rapidly. It is a closed conic subset of \(\Omega\times(\mathbb{R}^n\setminus\{0\})\), and its projection to \(\Omega\) is the singular support of \(u\) [1].

On a smooth manifold \(X\), the coordinate definitions agree under change of chart and give an intrinsic closed conic subset
\[
  \operatorname{WF}(u)\subset T^*X\setminus 0,
\]
where the covector, rather than a tangent vector, is the natural frequency variable [1].

### Mathematical Context and Formation

The motivating problem class is the regularity analysis of distributional solutions of linear equations
\[
  Pu=f,
\]
where \(P\) is a differential or pseudodifferential operator. The central questions are local and directional: near a chosen point, does \(u\) fail to be smooth in every high-frequency direction or only in directions where the principal symbol of \(P\) vanishes, and, in the latter case, along what phase-space curves can the failure of smoothness move?

Distribution theory made singular solutions admissible, but its support and singular support retained only the base point \(x\). They could say where \(u\) was nonsmooth, not in which frequency direction it was nonsmooth. This loss is decisive for PDE because the principal symbol is a function \(p_m(x,\xi)\) on cotangent variables: at the same point \(x\), \(P\) may be elliptic for one nonzero \(\xi\) and characteristic for another. A global Fourier transform supplied frequency information but mixed contributions from different spatial locations, so it could not answer the required pointwise-directional question.

The defining construction joins the two missing pieces. Multiplication by a cutoff \(\phi\) localizes the distribution near \(x_0\); rapid decay of \(\widehat{\phi u}\) detects smoothness; and testing that decay only in a conic neighborhood of \(\xi_0\) preserves directional information while ignoring irrelevant frequency magnitude. Recording the failed tests as pairs \((x,\xi)\) places singularities in \(T^*X\setminus0\), the same phase space on which the principal symbol lives. This synthesis forms the wave front set and turns the regularity question for \(Pu=f\) into a geometric comparison among \(\operatorname{WF}(u)\), \(\operatorname{WF}(f)\), and the characteristic set of \(P\) [1].

### Essential Role

The wave front set makes the elliptic part of the regularity problem precise. If \(P\) has smooth coefficients and principal symbol \(p_m\), then microlocal elliptic regularity gives
\[
  \operatorname{WF}(Pu)\subseteq \operatorname{WF}(u)
  \subseteq \operatorname{WF}(Pu)\cup\operatorname{Char}(P),
  \qquad
  \operatorname{Char}(P)=\{(x,\xi)\ne0:p_m(x,\xi)=0\}.
\]
Consequently, wherever \(p_m(x,\xi)\neq0\), \(u\) and \(Pu\) have exactly the same microlocal smoothness; in particular, if \(Pu\) is smooth, every singular direction of \(u\) must be characteristic [1]. Singular support alone cannot express this conclusion because it omits \(\xi\).

For operators of real principal type, the remaining characteristic singularities are not merely confined to \(\operatorname{Char}(P)\): away from singularities introduced by \(f\), they propagate along the null bicharacteristics generated by the Hamilton vector field of the principal symbol [2]. The wave front set is the object on which this statement can be made, because its covector component both matches the symbol and evolves under the Hamiltonian flow. Hence it addresses two exact obstacles in the motivating problem: it separates elliptic directions, where inversion yields regularity, from characteristic directions, where inversion fails, and it reformulates the residual failure as propagation in cotangent phase space rather than as an undifferentiated set of singular points.

This was more than a finer label for singular support. It introduced the structural viewpoint that PDE regularity is local in position and direction simultaneously. The cutoff-Fourier definition supplies the local directional test, conicity captures the homogeneous high-frequency nature of singularity, and the cotangent-bundle realization makes symbol calculus and Hamiltonian propagation act on the same geometric object.

## 3. Notes

The wave front set should not be confused with the singular support: the latter is exactly its projection to the base manifold and therefore discards directional data. The analytic wave front set is a related but different object detecting failure of real analyticity rather than failure of \(C^\infty\)-smoothness. Criteria for products and pullbacks of distributions are important later uses of wave front sets, but they are distinct from the direct PDE regularity-and-propagation role emphasized here [1].
